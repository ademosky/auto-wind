# База на податоци (Supabase)

Сајтот очекува **три табели** и **една корпа за фотографии**:

| Објект | Што содржи |
|--------|-------------|
| `public.vehicles` | возилата и сите нивни спецификации |
| `public.vehicle_images` | фотографиите на секое возило (главна слика + редослед) |
| `public.site_settings` | контакт податоците (телефон, Viber, WhatsApp, адреса, работно време) |
| `vehicle-photos` (Storage) | самите фотографии |

Целата шема е во **[`migrations/0001_init.sql`](./migrations/0001_init.sql)** (истата содржина е и во `schema.sql`).
Скриптата е идемпотентна — може да се изврши повеќе пати без грешки.

---

## Како се поставува

1. Отвори го проектот во Supabase и оди во **SQL Editor**.
2. Копирај ја целата содржина на `migrations/0001_init.sql` и кликни **Run**.
3. Оди во **Storage** и провери дека постои корпата `vehicle-photos`.
4. Копирај ги вредностите во `.env.local` од **Settings → API Keys**:

```env
NEXT_PUBLIC_SUPABASE_URL=https://<ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon key>
SUPABASE_SERVICE_ROLE_KEY=<service_role key>
```

5. Провери врската:

```bash
npm run db:check
```

## Грешки и решенија

### „Could not find the table 'public.vehicles' in the schema cache“

Ова значи едно од следниве три:

1. **`.env.local` покажува на погрешен Supabase проект.** Најчеста причина —
   вредностите се земени од друг проект (на пр. од претходен сајт). AUTO WIND
   работи на проектот со реф `pwajzhkcpemekrvvhdqs`. Провери ја
   `NEXT_PUBLIC_SUPABASE_URL` и отвори ја таа адреса во Supabase:
   дали тоа е проектот во кој ја изврши шемата?
2. **Шемата не е извршена.** Изврши `migrations/0001_init.sql` во SQL Editor.
3. **Кешот на Supabase не е освежен.** По извршувањето на шемата, изврши:

   ```sql
   notify pgrst, 'reload schema';
   ```

   (Последната линија во `0001_init.sql` го прави ова автоматски.)

   Најбрза проверка на сите три работи одеднаш:

   ```bash
   npm run db:check
   ```

### Празна понуда, без грешка

Табелите постојат, но нема внесени возила. Внеси ги од admin панелот (`/admin`).

### Фотографиите не се качуваат

- Провери дека `SUPABASE_SERVICE_ROLE_KEY` е пополнет во `.env.local` (без него admin панелот
  не може да запишува).
- Провери дека корпата `vehicle-photos` постои (се создава со шемата).
- Дозволени формати: JPG, PNG, WEBP, AVIF, до 10 MB по фотографија.

---

## Безбедност

- Сајтот (она што го гледаат посетителите) го користи **anon** клучот и може само да чита.
- Admin панелот работи преку серверот со **service_role** клуч. Тој клуч **никогаш**
  не оди во GitHub и не се става во код што се извршува во браузер.
- `.env.local` е наведен во `.gitignore` — никогаш не го додавај во репозиториумот.
