# AUTO WIND

Веб-сајт за AUTO WIND — увоз и продажба на половни автомобили.
Домашна страница со актуелна понуда, посебна страница за секое возило со галерија и спецификации, директен контакт, и admin панел за управување со возилата.

---

## Локално стартување

Потребни ти се **Node.js 20 или понова верзија** и **npm**.

```bash
# 1. Инсталирај ги пакетите
npm install

# 2. Постави ги поставките (види го делот „Поставки“ подолу)
cp .env.example .env.local

# 3. Стартувај
npm run dev
```

Сајтот се отвора на **[http://localhost:3000](http://localhost:3000)**.

За продукциска проверка локално:

```bash
npm run build && npm run start
```

## Поставки

Целиот сајт се води преку `.env.local`. Копирај го `.env.example` и пополни го:

```env
# --- База и фотографии (Supabase) ---
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...

# --- Admin најава ---
ADMIN_EMAIL=your@email.com
ADMIN_PASSWORD=смени-ја-оваа-лозинка
ADMIN_SESSION_SECRET=долг-случаен-стринг

# --- Адреса на сајтот ---
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

**Важно:**

- Клучевите од Supabase се во **Settings → API Keys** во Supabase проектот (проектот **auto-wind**).
- Провери дека врската работи со `npm run db:check` — ќе ти каже точно што недостасува.
- Целата шема на базата и решавање на грешки: **[supabase/README.md](supabase/README.md)**.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` е публичен клуч — се користи на сајтот за читање на возилата.
- `SUPABASE_SERVICE_ROLE_KEY` е **таен** клуч — се користи само на серверот за admin панелот. Никогаш не го ставај во GitHub и не го споделувај.
- За промена на лозинката за admin: смени ја `ADMIN_PASSWORD` во `.env.local` и рестартирај. Така се враќа пристап и ако ја заборавиш.

## Како да додадеш прво вистинско возило

1. Отвори **http://localhost:3000/admin** и најави се со `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
2. Кликни **„Ново возило“**.
3. Пополни марка, модел, година, цена и останатите податоци. Зачувај.
4. На страницата на возилото, во делот **„Фотографии“**, повлечи ги фотографиите или избери ги рачно. Првата фотографија автоматски станува главна.
5. Со копчињата **↑ ↓** го менуваш редоследот, со **„Главна“** избираш која фотографија се прикажува во понудата.
6. Возилото еднаш е зачувано — веднаш се појавува на сајтот на адреса `/vozila/марка-модел-година`.

**Статуси на возило:**

- **Достапно** — се прикажува во понудата.
- **Резервирано** — се прикажува со ознака „Резервирано“.
- **Продадено** — не се прикажува во активната понуда, туку во секцијата „Неодамна продадени“ со SOLD ознака.

## Фотографии

- Дозволени формати: **JPG, PNG, WEBP, AVIF**, максимум **10 MB** по фотографија.
- Се качуваат во Supabase Storage (`vehicle-photos`), во папка со идентификаторот на возилото.
- Ги прикажуваме со автоматска оптимизација (различни големини, lazy loading), па сајтот останува брз и со многу фотографии.
- Кога бришеш возило од admin панелот, се бришат и неговите фотографии.

## Технологии

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** со брендиран дизајн систем (emerald / champagne gold)
- **Supabase** — Postgres база, Storage за фотографии, row level security
- **lucide-react** за икони
- Оптимизација: `next/image`, AVIF/WEBP, статично генерирани страници на возила, `sitemap.xml`, `robots.txt`, Open Graph слика
